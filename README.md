## Work projects

The code of these projects is proprietary. The links open a write-up of the method.

| Project | What it does | Where |
|---|---|---|
| [Adaptive payment-gateway router](https://lagnis337.github.io/projects/adaptive-gateway-router.html) | Selects a payment gateway for each transaction and learns from each result. It uses an upper confidence bound (UCB) bandit with drift detection. A PPO policy was trained on a simulator but is not in the decision path. | Razorpay |
| [Driver churn prediction](https://lagnis337.github.io/projects/driver-churn.html) | Gives a churn score each morning to approximately 150,000 drivers, from an average of XGBoost and a random forest on 36 features. Monthly churn decreased from 42% to 30% in three months. | Namma Yatri |
| [Driver safety enforcement](https://lagnis337.github.io/projects/driver-safety-enforcement.html) | Translates rider feedback with the Sarvam API and puts each complaint in one of five severity groups. The system then decreases the priority of the driver, or blocks the driver after a person confirms. Safety complaints decreased by approximately 50%. | Namma Yatri |
| [Slack-native AI analyst](https://lagnis337.github.io/projects/text-to-sql-analyst.html) | More than 2,000 documents became one approved data wiki. A model-agnostic Slack agent reads the index, opens the necessary pages, and runs read-only SQL. 96% of the answers got a positive rating, and approximately 40% of a team of 127 persons asked a question every day. | Razorpay |
| Voice AI support agent | A driver support agent on Gemini Live that answers in less than one second and speaks more than one language. The resolution time decreased by 75%. | Namma Yatri |
| Offer-propensity ranking | A ranking model that scores the probability that a customer uses an offer, by type, time, and product. The net revenue for each outlet increased 3 times. | Uber |
