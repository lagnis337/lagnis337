# Hi, I'm Chirag Singal 👋

I'm preparing for graduate study in **Data Science / Machine Learning**. Alongside coursework and self-study, I like building small, end-to-end projects to understand how things actually work — from the database layer up to the browser.

## Projects

### 📋 [Log Ingestor](https://github.com/lagnis337/logs_ingestor) — Node.js · Express · PostgreSQL
A web service that ingests JSON application logs into PostgreSQL and lets you search them with any combination of eleven filters (level, message text, resource, trace/span IDs, commit, time and date ranges).
*What I learned:* using PostgreSQL's JSON operators to flatten nested documents into typed columns, building dynamic parameterised SQL safely, and structuring a small REST service.

### 🛗 [Lift Simulator](https://github.com/lagnis337/Lift_Simulator) — HTML · CSS · JavaScript
An interactive simulation of a building with up to 15 floors and 4 lifts. Lifts are dispatched to button presses, animate with distance-proportional travel time, open and close their doors, and queue requests when every lift is busy. No frameworks — just the DOM.
*What I learned:* managing asynchronous state (timers, queues, busy flags) in the browser, CSS transitions, and responsive layout.

Each repository has a README with setup instructions and a step-by-step "try it out" section.
